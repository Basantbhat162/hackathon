# Team research

This folder holds team-supplied ideas, first-hand accounts, early project breakdowns, and working analysis. These files preserve input and reasoning; they are not the current project state.

## Contents

- `My Thoughts.md`: Basant's original project and delivery concerns.
- `My friend q&a.md`, `My friend analysis.md`, and `My friend analysis2.md`: team-member idea material and evaluations.
- `PF_Nikal_Project_Breakdown.md` and `PF_Nikal_Sourced_Reference.md`: early PF Nikal scope and source notes.
- `hackathon-winning-playbook.md`: non-authoritative raw delivery advice retained for provenance.

Record accepted decisions in `../../project-docs/RESEARCH_AND_DECISION_LOG.md`, current state in `../../project-docs/PROJECT_STATE.md`, and verified contribution or rights information in its established owner. Do not rewrite first-hand evidence to make it fit the project.
