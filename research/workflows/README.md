# Research workspace

This folder separates raw tool instructions, prompts, and returned research.

## Existing reference files

- `comet-browser-assistant.md`: observed operating instructions for Comet Browser Assistant.
- `deep-research.md`: observed operating instructions for Perplexity Deep Research.

These files describe how the tools are expected to behave. They are not official hackathon sources and do not prove that every tool result is correct.

## Folder map

- `shared/`: run order, source rules, team interview, and result template.
- `comet-browser/prompts/`: browser-led research prompts.
- `comet-browser/results/`: raw Comet Browser results pasted by the team.
- `perplexity-deep-research/prompts/`: Perplexity Deep Research prompts.
- `perplexity-deep-research/results/`: raw Deep Research results pasted by the team.
- `crawlee-later/`: deferred notes about Crawlee. It is not part of the current research run.
