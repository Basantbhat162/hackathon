# Reference material

This folder contains supplied or reusable source material. It does not contain project decisions or raw research results.

## Folder map

- `official-hackathon/`: supplied Build What Moves India material. These files alone can establish mandatory hackathon rules.
- `workspace-design/`: non-authoritative reports and playbooks about agent and workspace design. Adopt ideas only through current project rules or recorded decisions.

## Official authority order

1. `official-hackathon/Builder brief.md`
2. `official-hackathon/Frequently asked questions.md`
3. `official-hackathon/Website.md`
4. `official-hackathon/APPLY NOW.md` and `official-hackathon/Form reg.pdf`
5. Team research and outside comments

Do not place commentary, summaries, or derived research in `official-hackathon/`. Preserve supplied files as source evidence.
